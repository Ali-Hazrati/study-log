## Typography

The site bundles the [Vazirmatn](https://github.com/rastikerdar/vazirmatn) v33.003
variable font (weights 100–900) in `assets/fonts/`. It is served locally without
a third-party font CDN. Its SIL Open Font License is included in
`assets/fonts/OFL.txt`.
